Use Token Tally with your own data

Token Tally runs on your own computer and reads the logs that Claude Code and Codex already keep there. Your numbers never leave your computer.

Enter your email to get the install command

We save only your email, to count users and send rare updates. You can ask us to delete it at any time.

  1. Install Node.js 20 or newer from nodejs.org, if you do not have it.
  2. Open Terminal and paste this line:
npx -y @manyatamanocha/token-tally
  1. Type y when it asks to connect to Claude Code. Your live dashboard then opens in your browser.
